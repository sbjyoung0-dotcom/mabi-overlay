# mabi-overlay

마비노기 모바일 PC 클라이언트 위에 띄우는 투명 오버레이. 가공 시설 현황·수령, 채집/가공 즐겨찾기, 자동 재가공.
게임 정보는 넥슨 공식 `MabinogiMobile_CLI.exe`를 직접 호출해서 받는다. AI 도구는 필요 없다.

## 설치 (3단계)

1. 게임 설정 → [게임/기타] → **MM AI 에이전트 활성화** 켜기 (이걸 켜면 넥슨 공식 CLI가 자동 설치된다)
2. [Releases](https://github.com/sbjyoung0-dotcom/mabi-overlay/releases)에서 **`mabi-overlay-setup-x.y.z.exe`** 를 받아 더블클릭 → 설치가 끝나면 자동 실행되고 바탕화면에 바로가기가 생긴다
   - "알 수 없는 게시자" 경고가 뜨면 **추가 정보 → 실행** (코드 서명이 없어서 나오는 경고)
   - 관리자 권한은 필요 없다(사용자 폴더에 설치됨)
3. MoFo 등 다른 CLI 호출 프로그램은 끄고 쓴다 — 동시에 돌리면 게임 응답이 섞인다

업데이트는 새 setup 파일을 받아 다시 실행하면 덮어쓰기 된다. 설정·캐릭터 기록은 `%APPDATA%\mabi-overlay`에 있어 유지된다.
제거는 Windows 설정 → 앱에서 "mabi-overlay" 제거.

CLI가 기본 경로(`C:\`, `D:\`, `E:\Nexon\MabinogiMobile\` 순으로 탐색)에 없으면 환경변수 `MABINOGI_CLI_PATH`에 전체 경로를 지정한다.


## 개발
```
npm install
npm test
npm start
```

## 배포판 만들기
```
npm run build        # 원클릭 설치 파일 → dist/mabi-overlay-setup-<버전>.exe
npm run build:dir    # 압축 안 된 폴더 → dist/win-unpacked/ (개발 확인용)
```
코드 서명이 없어 첫 실행 시 SmartScreen 경고가 뜬다.

## 조작
- 위젯 밖은 게임으로 클릭이 통과한다. **F8**: 위젯까지 완전 관통 토글.
- 위젯 클릭 판정은 커서 좌표 폴링 방식이라 게임 창이 앞에 있어도 동작한다.
- F8: 게임 창이 앞에 있을 때는 시스템이 단축키를 전달하지 않을 수 있다 → 위젯을 한 번 클릭한 뒤 F8, 또는 **트레이 아이콘(주황 사각형) 우클릭 → 완전 관통 모드**를 사용한다. 완전 관통 해제도 같은 방법.
- 트레이 메뉴: 오버레이 보이기 / 표시 모니터 / 완전 관통 모드 / 위치 잠금 / 위젯 위치 초기화 / 종료.
- **🙈 숨기기**: 오버레이를 감춘다. 트레이 아이콘을 클릭하거나 트레이 메뉴의 "오버레이 보이기"로 되돌린다. 숨긴 동안에는 커서 폴링도 멈춘다.
- ⚙ → **위젯 표시**: 안 쓰는 위젯(예: 제작)을 끈다. 숨긴 위젯은 마우스 판정에서도 빠져 그 자리의 게임 클릭을 막지 않는다. 가공 현황은 툴바를 품고 있어 항상 표시된다.
- 🔒 클릭 → ✋: 헤더를 드래그해 위치 이동. 다시 클릭해 잠금.
- ⚙: 채집/가공 즐겨찾기(게임 연결 상태에서 목록 불러오기), 자동 재가공, 시설 표시.
- 자동 재가공은 즐겨찾기별 "N건 완료 시 수령" 기준을 두며, 더 완료될 건이 없으면 기준 미달이라도 수령한다.
- 🔁: 자동 재가공 전체 일시정지/재개.
- F8은 오버레이 실행 중 시스템 전역으로 가로채므로 게임의 F8 기능은 쓸 수 없음.

## 제한과 모니터 설정

- 게임은 창 모드 또는 테두리 없는 창 모드여야 한다. 전체화면 독점 모드에서는 오버레이가 보이지 않는다.
- 오버레이는 **한 모니터 안에만** 표시된다. 여러 모니터를 한 창으로 덮으면 주사율이 다른 환경에서 해당 모니터 출력이 멈추는 문제가 있어(실측 144/120/60Hz 혼합) 그렇게 하지 않는다.
- 표시할 모니터는 **트레이 아이콘 우클릭 → 표시 모니터**에서 고른다. 목록은 왼쪽→오른쪽 순서다. 선택은 저장되며, 모니터를 다시 연결해 내부 id가 바뀌어도 좌표로 같은 모니터를 다시 찾는다.
- 위젯은 그 모니터 밖으로 나가지 못하게 자동으로 안쪽으로 당겨진다. 그래도 안 보이면 트레이 → **위젯 위치 초기화**.

## 제작 (크래프팅)

⚙ → 제작 즐겨찾기에서 레시피와 횟수를 등록하면 "제작" 위젯에 버튼이 생긴다.

- 버튼 한 번이 **이동·제작·수령까지 한 번에** 끝난다(가공처럼 큐에 쌓이지 않는다).
- **정령의 날개는 호출당 5개**로, 횟수를 몇 번으로 하든 같다. 가공은 1건당 5개이므로 다르다.
- 시설마다 한 번에 가능한 최대 횟수가 있어, 넘기면 최대 횟수를 알려준다.
- 재료가 모자라면 확인창에 부족한 재료와 **다른 캐릭터가 얼마나 갖고 있는지**를 함께 보여준다(🔍 기록 기준).

## 가공 완료 알림

가공이 끝나면 Windows 알림으로 알려준다(⚙ → 알림에서 끌 수 있음). 자동 재가공이 켜진 항목은 알아서 수령하므로 알리지 않는다.

## 아이템 찾기 (🔍)

툴바의 🔍를 누르면 아이템 이름으로 보유량을 찾을 수 있다. **총 개수 / 계정창고(공용) / 직업별 가방·개인창고**를 나눠 보여준다.

- CLI가 캐릭터 이름을 주지 않으므로 **직업을 캐릭터 키로** 쓴다. 검색창을 열면 현재 접속 캐릭터의 목록이 자동 저장되고, 캐릭터를 바꿔 접속해 검색창을 한 번 열면 그 직업 칸이 쌓인다.
- 현재 접속 캐릭터와 계정창고는 실시간, 다른 직업은 마지막 저장 시각과 함께 회색으로 표시된다.
- 칩의 ✎로 이름 변경(예: `사제` → `사제(본캐)`), ✕로 기록 삭제.
- 같은 직업 캐릭터가 둘이면 한 칸을 공유해 나중에 연 쪽으로 덮어써진다.
- **장비·의상·펫은 CLI가 제공하지 않아 검색되지 않는다.** 소모품·재료·채집물만 대상.
- 기록은 `%APPDATA%\mabi-overlay\items-cache.json`에 저장된다.

## 비용
- `execute_gathering` 1회(최대 100개) = 정령의 날개 5개
- `execute_altering` 1건 = 정령의 날개 5개 (자동 재가공도 동일, 오늘 누적치는 가공 등록 위젯에 표시)

## 설정 파일
`%APPDATA%\mabi-overlay\config.json`
